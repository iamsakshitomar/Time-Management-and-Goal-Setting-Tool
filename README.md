# Time Management and Goal Setting Tool

Java Swing GUI project for Review 1.

## Features
- Login/register
- Dashboard
- Goal CRUD
- Task CRUD
- Goal/task progress
- Schedule management
- Background deadline reminder thread
- OOP: abstraction, inheritance, encapsulation, polymorphism
- Interface for reminders
- Collections and generics
- Exception handling
- JDBC CRUD using PreparedStatement
- Database transactions with commit/rollback
- SQLite database generated automatically

## Requirements
- JDK 17+
- Maven 3.8+
- Internet once for Maven to download the SQLite JDBC dependency

## Run
From the project folder:

mvn clean compile
mvn exec:java

Or run `timemanagement.Main` from an IDE after Maven dependencies are loaded.

## Default login
Register a user first. Passwords are stored as SHA-256 hashes for this student project.

## Database
A file named `time_management.db` is created automatically in the project directory.
